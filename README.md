# Microservices Repository  

This repository contains projects demonstrating **microservices architecture**. The **main branch** hosts a **complete Employee Management System**, while the **dev branch** contains various microservices components.  

## 📌 Branch Structure  

- **Main Branch**  
  - **Employee Management System** – A full-fledged microservices-based application for managing employees.  

- **Dev Branch**  
  - **Microservices Folder** – Contains individual microservices handling different functionalities.  

## 🚀 Technologies Used  

- **Java (Spring Boot)** – Backend microservices development  
- **Spring Cloud** – Microservices communication and configuration

1. Clone the repository:  
   ```bash
   git clone https://github.com/sauravkumar217/microservices.git
